# Methodology and Results

On Analyzing the dataset, I observed that The height column had inconsistent or incorrect data entries. So, at the initial stage, I replaced the values in the height column with random numbers ranging from 150 to 180. Then, I checked the total number of null values in each column and found that the columns college and salary contained 84 and 11 null values, respectively. In the next step, I dropped the null values in the college and salary columns. Then, I again checked for the presence of null values in each column and found that there were no null values in any of the columns. To ensure that each column had the correct data type, I used the data.dtypes function and verified that each column had the appropriate data type. Finally, in the team, college, and position columns, I obtained the unique values and their corresponding frequencies, thereby understanding how many times each unique value appeared in the different columns, including missing values and ensuring data consistency in each of these columns.

The next step was to determine the distribution of employees across each team and calculate the percentage split relative to the total number of employees. To perform this task, I obtained the unique values and their corresponding frequencies in the Team column. Then, I divided the count of employees in each unique category by the total number of employees in the dataset and multiplied the result by 100 to calculate the percentage of employees in each team relative to the total number of employees. To visually represent the distribution, I created a pie chart using Matplotlib and added a legend to indicate which slices represented the different teams. From the chart, it was observed that the New Orleans Pelicans had the maximum number of employees, accounting for 4.4% of the total employees. Thus, by analyzing the pie chart, I was able to identify the team with the highest number of employees and understand the distribution of employees across the different teams.

Proceeding Further, I segregated the employees based on their positions within the company. For this purpose, I used the groupby() function to group the employees according to their positions and obtained the count of non-missing values in each column corresponding to each position. I also reset the index of the Position column using the reset_index() function so that Position would be treated as a regular column rather than an index. To represent the results effectively, I used a bar plot from Seaborn, with Position on the x-axis and Name on the y-axis, to visualize the frequency of employees in each position. Since the Name column contained unique values and no duplicate records were found in the dataset, it could be used to determine the number of employees in each position. From the bar plot, it was observed that the SG (Shooting Guard) position had the highest number of employees, with a total count of 87, making it the position with the largest number of employees in the company.

The next step was to identify the predominant age group among employees. For this purpose, I extracted the Age column from the dataset and used the value_counts() function to obtain the frequency of each age value. From the resulting table, I observed that 42 employees belonged to the age group of 25, making it the predominant age group among the employees. To visually represent the distribution, I created a pie chart using Matplotlib and added a legend to indicate which slices corresponded to the different age groups. From the pie chart, it was clearly visible that 11.5% of the total employees belonged to the age group of 25.

Then the main task was to identify which team and position had the highest salary expenditure. For this purpose, I grouped the data based on Team and Position and calculated the mean salary corresponding to each team and position combination. I then used the reset_index() function to ensure that Team and Position were treated as regular columns rather than index labels. Next, I created a new column called Team_Position by combining the team and position values corresponding to each row. I then used the idxmax() function to identify the index label of the row containing the maximum mean salary and the .loc function to retrieve the corresponding salary value and team-position combination. The maximum mean salary was found to be 14,260,870.0, corresponding to the Golden State Warriors and the PF (Power Forward) position. To visually verify this result, I created a horizontal bar chart using the Team_Position and Salary columns. Upon analyzing the chart, I arrived at the same conclusion that the Golden State Warriors' PF position had the highest mean salary expenditure among all team-position combinations. Thus, both the numerical analysis and the graphical representation confirmed the same result.

As the final Task, I investigated whether there was any correlation between age and salary and to represent the relationship visually. For this purpose, I created a correlation table showing the correlation coefficients between Age and Salary. The diagonal elements of the table were equal to 1 because the correlation of a variable with itself is always 1, while the off-diagonal elements represented the correlation between different variables. From the table, the correlation coefficient between Age and Salary was found to be approximately 0.15992. To visually represent this relationship, I used a heatmap from Seaborn. From the heatmap, it was observed that Age and Salary had a weak positive correlation of approximately 0.16, indicating a very weak positive linear relationship between the two variables. Meanwhile, the diagonal elements displayed a correlation of 1 for each variable with itself.
